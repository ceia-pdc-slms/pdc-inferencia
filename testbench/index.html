Testbench

Escolha um pipeline, ajuste os parâmetros e execute. Cada execução grava um JSON com o resultado e a procedência, que pode ser comparado com qualquer outra medição do time.

A bancada não está rodando

Para executar pipelines a interface precisa do servidor da bancada: é ele que mede, sem passar pelo navegador. Comparar resultados funciona mesmo assim: arraste os JSON na aba Resultados.

  1. Na raiz do repositório: 
    python testbench/servidor.py
  2. Ou tudo em container (bancada + modelo): 
    docker compose up -d
  3. Abra http://localhost:8088/testbench/. O passo a passo completo está no README.

Como adicionar um pipeline

Um pipeline é um arquivo JSON em testbench/pipelines/: o comando a rodar e a lista de parâmetros. A bancada monta o formulário, valida os valores, roda o comando sem shell e guarda o JSON que ele gerar. Pode ser um script nosso, o llama-bench, o lm-eval, um docker run… Reinicie a bancada depois de criar o arquivo. Detalhes em testbench/README.md.

{
  "id": "perplexidade",
  "nome": "Perplexidade",
  "categoria": "Qualidade",
  "descricao": "…",
  "esquema_resultado": "ppl-v1",
  "comando": ["{python}", "-u", "{raiz}/testbench/pipelines/perplexidade.py"],
  "saida": { "argumento": "--out" },
  "progresso": "lote (\\d+)/(\\d+)",
  "parametros": [
    { "id": "url", "rotulo": "Servidor", "grupo": "Ambiente", "tipo": "texto",
      "padrao": "{modelo_url}", "argumento": "--url", "obrigatorio": true },
    { "id": "lotes", "rotulo": "Lotes", "grupo": "Carga", "tipo": "inteiro",
      "padrao": 20, "min": 1, "argumento": "--lotes" }
  ]
}
