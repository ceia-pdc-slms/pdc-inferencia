# reports

Análises que juntam várias medições: comparações entre máquinas, formatos e runtimes, fronteiras de Pareto, gráficos usados em apresentação.

Regra: todo número num relatório aponta para o arquivo de `runs/` ou `quality/` de onde saiu. Relatório sem link para os registros é opinião.

Nomeie como `AAAA-MM-DD_assunto.md`.
