# docs

- [Mapa do time](mapa-do-time.md): o que o time faz, as regras da reunião, o calendário de set a dez/2026, a pergunta de cada apresentação e as fontes por aula.

Decisões do time que valem registro (runtime padrão, formato de medição, divisão das equipes em janeiro) entram em `docs/decisoes/AAAA-MM-DD_assunto.md`: o que foi decidido, por quê, e o que ficou de fora.

O material das apresentações não fica aqui: fica em [`apresentacoes/`](../apresentacoes/), por semana e por pessoa.
